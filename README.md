# vite-fastapi

> Full-stack automation toolkit — Vite + React frontend with FastAPI backend & Python automation scripts
>
> ## 🚀 Overview
>
> **vite-fastapi** is a full-stack boilerplate and automation toolkit combining a blazing-fast Vite/React frontend with a Python FastAPI backend. Includes utility scripts for blacklist checking, API integrations (GlockApps, Notion), and more — designed for building production-ready automation tools fast.
>
> ## ✨ Features
>
> - ⚡ Vite + React frontend for instant hot-reload development
> - - 🐍 FastAPI backend with async endpoints
>   - - 🔍 Blacklist checker utility (email/domain reputation)
>     - - 📓 Notion API integration for data management
>       - - 📧 GlockApps API integration for email deliverability
>         - - 🔗 RESTful API architecture with clean separation of concerns
>          
>           - ## 🛠️ Tech Stack
>          
>           - | Layer | Technology |
>           - |-------|-----------|
>           - | Frontend | React, Vite, TypeScript |
> | Backend | Python, FastAPI |
> | APIs | Notion API, GlockApps API |
> | Package Manager | pip / npm |
>
> ## 📦 Getting Started
>
> ### Prerequisites
>
> - Python 3.9+
> - - Node.js 18+ and npm
>  
>   - ### Backend Setup
>  
>   - ```bash
>     # Clone the repository
>     git clone https://github.com/clutxhOP/vite-fastapi.git
>     cd vite-fastapi
>
>     # Install Python dependencies
>     pip install -r requirements.txt
>
>     # Run the FastAPI server
>     uvicorn main:app --reload
>     ```
>
> ### Frontend Setup
>
> ```bash
> # Install frontend dependencies
> npm install
>
> # Start the development server
> npm run dev
> ```
